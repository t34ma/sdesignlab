Sample Programs: Reading Binary Records in Fortran and C

Overview  
This package contains two sample programs, samplef.f90 (Fortran) and sample.c (C), which demonstrate how to read a custom binary file named data.bin.

The binary file consists of multiple records, each beginning with:  
1. Record type (integer)  
2. Length (integer)  
3. Payload (varies depending on the record type)

Note:  
data.bin is an example output generated by DuCOM-COM3, and these sample programs show how to interpret its binary record structure.

Binary Format Specification  
Each record in data.bin has the following structure:

Type 0: String record  
    Payload: length bytes of character data

Type 1: Integer + real array  
    Payload: 1 integer + length real(4) values

Type 2: Two integers + real array  
    Payload: 2 integers + length real(4) values

All integers are stored as 4-byte values.  
All real numbers are stored as 4-byte IEEE 754 floating-point values.

Program Description (samplef.f90)  
The Fortran program samplef.f90:

- Opens data.bin using stream/unformatted access  
- Reads records sequentially until end-of-file  
- Allocates memory dynamically based on record length  
- Prints strings, integers, and real arrays  
- Handles unknown record types gracefully  
- Uses only standard Fortran features for portability

The C program sample.c provides an equivalent implementation using fread() and malloc(), but the Fortran version is the primary reference.

How to Build

Fortran (samplef.f90)  
Intel Fortran (ifort / ifx):  
    ifort samplef.f90 -o samplef.exe  
or  
    ifx samplef.f90 -o samplef.exe  

GNU Fortran:  
    gfortran samplef.f90 -o samplef.exe  

C (sample.c)  
    gcc sample.c -o sample.exe  

How to Run

Fortran version:  
    ./samplef.exe  

C version:  
    ./sample.exe  

Both programs will read data.bin from the current directory and produce output similar to:

[TYPE 0] String = 'Hello'  
[TYPE 1] Integer: 3  
           Reals:  1.000  2.000  3.000 ... 
[TYPE 2] Integers: 10 20  
           Reals:  0.500  0.750  1.250 ... 
File reading completed.

For the actual output generated from the provided data.bin by the Fortran program, please refer to output.txt.

Notes  
- Both programs avoid compiler-specific extensions.  
- samplef.f90 uses allocatable arrays; sample.c uses malloc()/free().  
- These samples are intended as reference implementations for reading DuCOM-COM3 binary output.

DUCOM_BINARY_OUTPUT
Switches output format from text to binary

APPLICATION
DuCOM / COM3 - MT and MPI versions

SYNTAX
DUCOM_BINARY_OUTPUT=<flag>

ARGUMENTS
<flag> - Logical flag
T: Enable binary output
F: Use text output (default)

DESCRIPTION
This environment variable controls whether output files are written in binary format.
By default, output is written in human-readable text.
Setting DUCOM_BINARY_OUTPUT=T enables binary output, which is more compact and
suitable for post-processing or high-performance I/O. Binary output typically
reduces file size by approximately one third compared to text output.

EXAMPLE USAGE
Linux (IntelMPI):	mpirun -env DUCOM_BINARY_OUTPUT=T ./SolverMPI
Windows:		set DUCOM_BINARY_OUTPUT=T && SolverMT.exe

ADDITIONAL NOTES
Binary records follow a structured format consisting of:
- type (INTEGER): Record format identifier
- length (INTEGER): Number of values or characters
- values: Data payload depending on type
Record types:
type = 0: Character string (length = number of characters)
type = 1: One integer followed by real values
type = 2: Two integers followed by real values
